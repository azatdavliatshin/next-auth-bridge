## Known issues / tech debt (non-blocking)

- **Keycloak provider-agnostic CI job fails to start its service container** in GitHub
  Actions (Keycloak 26.0.7 image needs an explicit `start-dev` command the GHA
  service-container block can't supply; dies at "Initialize containers"). The proof
  artifacts (browserless auth-code+PKCE/S256 helper, the real bridge→consume roundtrip
  test, the `directAccessGrantsEnabled:false` realm) all exist and the tests pass locally
  with env; only the CI execution is environment-blocked. The keycloak-roundtrip check is
  NOT a required status check, so it does not block merges or releases. Recommended fix:
  run Keycloak via an explicit `docker run`/compose `start-dev` step instead of the
  service-container block. (Recorded in 05-VERIFICATION.md known_issues.)
