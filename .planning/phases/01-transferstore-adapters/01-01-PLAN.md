<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → store | A future caller (Phase 2 `/auth/bridge`) requests a code; the store must guarantee entropy by construction so no caller can supply or influence a weak code |
| store → persistence | The store hands `{payload, expiry}` to a backend; the backend (in-memory Map or KV) must enforce one-time-use and TTL atomically |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | generate-code.ts (handle entropy) | mitigate | 256-bit CSPRNG via `randomBytes(32).toString('hex')` at a SINGLE site (D-01); no caller-supplied entropy on the `create()` signature; entropy test asserts length 64 / charset `^[0-9a-f]{64}$` / 10k-uniqueness (STORE-04 / THREAT-02). HIGH severity — blocking; entropy guaranteed by construction |
| T-01-02 | Information Disclosure | consume() miss-mode handling (contract) | mitigate | All three miss modes (not-found / expired / already-consumed) collapse to `null` with no per-mode branch or timing signal (D-03); the contract suite asserts consume-of-unknown returns null identically to second-consume (no oracle) |
| T-01-03 | Tampering | TransferPayload stored shape | mitigate | Provisional payload `{ authCookieValue: string }` carries NO mode-discriminating field; contract suite asserts the stored shape has no mode key + type comment cites STORE-01/v0.2 forward-compat (D-06) — a future discriminator fails the test and is visible in review |
| T-01-SC | Tampering | npm installs (@upstash/redis, tsup, vitest, typescript, @types/node) | accept | All packages cleared by RESEARCH Package Legitimacy Audit (slopcheck [OK] for @upstash/redis/tsup/typescript; vitest [SUS] is a documented false positive — CLAUDE.md-mandated, 6M+/wk, official repo). No package declares a postinstall script. No [ASSUMED]/[SUS]-requiring-checkpoint package remains → no blocking human checkpoint required |

No HIGH-severity threat is left unmitigated in this plan. T-01-01 is the security-critical invariant of the phase and is mitigated by construction.
</threat_model>
