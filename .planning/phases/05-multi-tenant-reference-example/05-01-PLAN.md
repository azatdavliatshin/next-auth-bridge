<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cross-site host-shell -> embedded iframe (tenant app) | Third-party context where ordinary cookies are blocked; the bridge + CHIPS partitioned cookie exist precisely for this seam. Wired here (allowedOrigins cross-site, per D-09), exercised live in Plan 05. |
| popup (top-level) -> opener (iframe) via postMessage | The `/auth/popup` page posts the opaque handle to its opener; the receiver pin (`hostOrigin`) must be the exact origin, never `"*"`. |
| client -> `/auth/bridge` (mint) and `/auth/consume` (redeem) | The package handlers enforce the session gate and one-time-handle exchange; the example mounts them unchanged. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Spoofing | `/auth/popup` postMessage target | mitigate | Pass an explicit `hostOrigin` to `runPopupFlow` (the package pins the receiver origin); `"*"` is forbidden in the page source (acceptance criterion greps for it). |
| T-05-02 | Elevation of Privilege | middleware context routing | mitigate | Middleware is UX-only via `createBridgeMiddleware` (reads `Sec-Fetch-Dest`); `isAuthenticated` is cookie-presence, NOT the gate. The real gate is `verifySession: () => auth()` on the bridge route. No security decision rides on detection. |
| T-05-03 | Information Disclosure | Edge middleware import graph | mitigate | Middleware imports only `createBridgeMiddleware` (store-free graph); the KV store / `@upstash/redis` / `node:crypto` never enter Edge (acceptance criterion greps the middleware file). |
| T-05-04 | Tampering | committed `.env.example` / source | mitigate | Only placeholder values committed (D-04 — secrets live in Vercel/GitHub Actions only); acceptance criterion asserts no real secrets and no internal req-IDs in shipped source. |
| T-05-SC | Tampering | npm installs (next-auth, @upstash/redis, next, react) | accept | RESEARCH Package Legitimacy Audit ran slopcheck 0.6.1 clean ([OK]) against all phase packages — all mature, high-download, known source repos; no `[ASSUMED]`/`[SUS]`/`[SLOP]`. No install checkpoint required. |
