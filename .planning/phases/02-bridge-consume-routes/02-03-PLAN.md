<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /auth/consume | The `code` and `next` query params and the `Origin` header are attacker-controllable; the one-time opaque handle (Phase 1 store) and `sanitizeNext` are the gates. |
| stored payload → Set-Cookie | The re-set cookies must carry the hardened CHIPS floors regardless of the (un-echoed) source attributes (D-02/D-03). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| THREAT-06 | Tampering / Spoofing | handle exchange in `createConsumeHandler` | mitigate | `store.consume` is atomic delete-first with `null`-on-miss (Phase 1); forged/expired/already-consumed all → `4xx` no-cookie. Negative tests: forged handle and replay (consume twice) each assert `4xx` + empty `getSetCookie()`. |
| T-02-AM1 | Denial of intended function / Input validation | absent/empty `code` guard (AM-1) | mitigate | A guard rejects absent/empty `code` with `4xx` no-cookie BEFORE `store.consume` is called — no null/empty argument reaches the store, preserving the no-oracle property and preventing a malformed-input crash. Test asserts the store is not reached. |
| ROUTE-03 / CHIPS | Denial of intended function | partitioned cookie-writer (D-02/D-13) | mitigate | Each chunk re-set via `Headers.append('Set-Cookie', …)` with `Secure; HttpOnly; SameSite=None; Path=/; Partitioned` (one append per chunk, never comma-joined). Test asserts every attribute via `getSetCookie()`. |
| T-02-08C | Tampering | redirect target (`sanitizeNext` wiring) | mitigate | `next` is passed through `sanitizeNext` before becoming the `Location`; unsafe targets degrade to `/`. Test: unsafe `next` on a valid handle → `Location: /`. |
| T-02-12C | Spoofing | Origin allowlist on consume (D-12/D-14) | accept (defense-in-depth) | Present-but-disallowed Origin → `4xx`; absent Origin proceeds to the handle gate. Documented as complementary to the one-time-handle boundary. Tests assert both arms. |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages. No legitimacy checkpoint required. |
</threat_model>
