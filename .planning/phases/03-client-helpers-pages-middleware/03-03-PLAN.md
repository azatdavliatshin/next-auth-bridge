<objective>
Build `openAuthPopup(deps)` — the opener-side (embedded iframe app) helper that opens `/auth/popup`, awaits the popup's `postMessage`, enforces the `postMessage` origin+source checks on receipt by delegating to 03-01's `isTrustedMessage` (THREAT-03), and resolves the `{ code }` to the caller (CLIENT-02). It returns a single awaitable promise with typed, distinguishable rejections (D-04) and cleans up its listener + close-poll on settle.

Purpose: This is the receiver half of the handoff and the security-critical consumer of the trust predicate — the `{ code }` is a bearer handle (D-01), so a message failing either the origin allowlist OR the `event.source === popupWin` identity check must be dropped and never resolve the flow. The promise contract (resolve `{ code }` / reject typed on auth-error, popup-closed, timeout, with full listener+poll cleanup) is the awaitable the embedded app uses before it drives `/auth/consume` itself.

Output: `open-auth-popup.ts` + its colocated test (resolve path + all three typed rejection paths + cleanup-on-settle). Depends on 03-01 (`isTrustedMessage` + the DI fakes); parallel to 03-02 (disjoint files).
</objective>

| Boundary | Description |
|----------|-------------|
| popup → opener (`postMessage`) | The inbound message is untrusted; the opener must validate origin AND source identity before reading the `{ code }` bearer handle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 (THREAT-03) | Spoofing | `openAuthPopup` message receipt | mitigate | Delegate the origin allowlist + `event.source === popupWin` identity check to `isTrustedMessage`; a wrong-origin OR wrong-source message is ignored and never resolves the flow (asserted). Plus a `source: 'next-auth-bridge'` namespace filter for foreign messages. |
| T-03-08 (THREAT-03) | Information Disclosure | bearer handle resolution | mitigate | The `{ code }` is only resolved after BOTH checks + namespace + type discriminator pass; a racing same-origin sender (allowed origin, wrong source) is rejected by the identity check. |
| T-03-09 | Denial of Service | listener/poll leak on settle | mitigate | Idempotent `cleanup()` unsubscribes the listener and clears the close-poll + timeout on every settle path (resolve and all rejections); asserted via the fake bus/timer recorders. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (03-RESEARCH.md Package Legitimacy Audit). Hand-rolled function only. No slopcheck checkpoint required. |
